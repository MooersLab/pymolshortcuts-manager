`README.md` at the repository root and by `index.rst`.

## Contents

| File | Tab | Shows |
|:-----|:----|:------|
| `Installation.png` | Installation | Downloading `pymolshortcuts.py`, detecting the operating system, and installing `psico` and `pyqtdarktheme` |
| `Shortcuts.png` | Shortcuts | The searchable, sortable table of every parsed shortcut with its detail pane |
| `AddShortcut.png` | Add Shortcut | The structured docstring form used to author a shortcut and open a pull request |
| `AIAssistant.png` | AI Assistant | Asking a natural-language question answered by retrieval over the shortcuts file |
| `AgenticAI.png` | Agentic AI | Wiring a coding harness to generate, validate, and document a new shortcut |

| `Tutorial.png` | Tutorial | One of the guided walkthroughs that run commands in PyMOL |

| `Settings.png` | Settings | Cross-session preferences backed by QSettings |
| `Links.png` | Links | Curated hyperlinks to documentation and related resources |

## Adding a screenshot

Capture at the plugin's default window size of 900 by 700 pixels or larger,
save as PNG, and name the file after the tab in PascalCase. Then add a row
to the table above and a line to the list at the end of `LICENSE`.

By contributing an image here you agree to license it under CC BY 4.0.
